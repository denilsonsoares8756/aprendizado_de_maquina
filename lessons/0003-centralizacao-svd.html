Centralização por Usuário
no SVD — Por que funciona

Foco desta lição: Ao final você vai conseguir explicar numericamente por que subtrair μᵤ resolve o problema dos zeros — e responder a pergunta mais provável da banca: "Como a centralização resolve o viés?"

O problema: zeros que não significam zero

Quando montamos a matriz usuário × filme, colocamos 0 em todo par não avaliado. Mas notas reais vão de 0,5 a 5,0. O SVD não sabe a diferença entre "não avaliou" e "avaliou com nota zero". Resultado: o modelo aprende que a nota esperada de qualquer par é próxima de zero.

Veja com um exemplo mínimo — 2 usuários, 4 filmes:

Matriz original R (sem centralização)

TitanicMatrixToy StoryGladiador
Ana540 ←ausente0 ←ausente
Bruno0 ←ausente0 ←ausente34
Problema: O SVD lê a linha de Ana como [5, 4, 0, 0]. Ele aprende que Ana "odeia" Toy Story e Gladiador. Na verdade, ela simplesmente não os assistiu. O modelo vai predizer notas baixíssimas para filmes não avaliados por Ana.

A solução: centralizar por usuário

Antes de passar a matriz para o SVD, subtraímos de cada nota a média daquele usuário (calculada apenas sobre as notas observadas).

r̃ᵤᵢ = rᵤᵢ − μᵤ

Passo 1 — Calcular μᵤ para cada usuário

Média de Ana (filmes avaliados: Titanic=5, Matrix=4) μ_Ana = (5 + 4) / 2 = 4.5

Média de Bruno (filmes avaliados: Toy Story=3, Gladiador=4) μ_Bruno = (3 + 4) / 2 = 3.5

Passo 2 — Subtrair μᵤ das notas observadas

Notas centralizadas de Ana Titanic: 5 − 4.5 = +0.5 (gostou mais que sua média)
Matrix: 4 − 4.5 = −0.5 (gostou menos que sua média)
Toy Story: ausente → 0 (mantém zero)
Gladiador: ausente → 0 (mantém zero)

Notas centralizadas de Bruno Titanic: ausente → 0
Matrix: ausente → 0
Toy Story: 3 − 3.5 = −0.5 (abaixo da média de Bruno)
Gladiador: 4 − 3.5 = +0.5 (acima da média de Bruno)

Matriz centralizada R̃ que o SVD recebe

TitanicMatrixToy StoryGladiador
Ana+0.5−0.500
Bruno00−0.5+0.5
Por que isso resolve: Agora o zero ausente significa "desvio zero em relação à média do usuário" — uma suposição razoável de que o usuário teria uma reação mediana ao filme. O SVD não confunde mais "não avaliou" com "odeia".

Passo 3 — Predição: somar μᵤ de volta

O SVD aprende a decompor R̃. Para fazer uma predição, calculamos o produto latente e somamos a média do usuário de volta:

r̂ᵤᵢ = μᵤ + uᵤᵀ vᵢ

Suponha que após o SVD, o produto latente ũ_Ana · v_ToyStory = −0.1 (Ana tende levemente a gostar menos de animações que a média).

Predição: nota de Ana para Toy Story r̂ = μ_Ana + (produto latente)
r̂ = 4.5 + (−0.1) = 4.4

Sem centralização, o mesmo modelo prediz: r̂ ≈ 0 + 0 = ~0 ← erro absurdo (nota real seria ~4)

O contraste que explica o resultado

Sem centralização

O SVD aprende que entradas ausentes (zeros) são "notas zero". Para qualquer filme não visto, prediz próximo de zero. RMSE = 3,43 — pior que o baseline ingênuo.

Com centralização

Zeros ausentes viram "desvio zero em relação à média do usuário". O modelo aprende preferências individuais sobre a média. RMSE = 0,96 — supera o baseline.
