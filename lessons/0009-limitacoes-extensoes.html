Limitação 1 — Cold Start

LIMITAÇÃO

O SVD aprende um vetor latente de 50 dimensões para cada usuário e cada filme a partir das avaliações observadas no treino. Um usuário novo não tem nenhuma avaliação → não tem vetor latente → o modelo não consegue recomendar nada.

Por que não dá para "calcular" um vetor para usuário novo O vetor do usuário u é: user_factors[u] = R̃[u, :] × Vᵀ

R̃[u, :] é a linha de avaliações centralizadas de u na matriz de treino.
Se u nunca avaliou nada → R̃[u, :] = vetor de zeros → user_factors[u] = zero.

Predição: r̂ = μ_u + 0 · v_i = μ_u (média global, sem personalização)
Impacto real: um usuário que acabou de se cadastrar recebe a mesma recomendação que qualquer outro — os filmes mais populares globalmente. Sem personalização até acumular avaliações suficientes.
Extensão 2 mitiga isso: incorporar features de conteúdo (gênero, ano, tags) permite recomendar filmes novos e para usuários novos sem depender de avaliações. Um usuário que declara "gosto de drama" no cadastro já tem um perfil mínimo.

Limitação 2 — SVD Estático

LIMITAÇÃO

O TruncatedSVD faz uma decomposição única da matriz de treino. Quando um usuário faz uma nova avaliação depois do treino, o modelo não atualiza — o vetor latente dele permanece o mesmo de quando foi treinado.

Custo de retreinar do zero com cada nova avaliação Matriz de treino: 137.168 usuários × 12.315 filmes × 50 componentes
TruncatedSVD com ARPACK: O(n × m × k) por iteração
= O(137.168 × 12.315 × 50) ≈ 84 bilhões de operações por retreino

Com 25M de novas avaliações por dia: retreinar em tempo real é inviável.
Extensão 1 mitiga isso: o ALS (Alternating Least Squares) pode atualizar o vetor de um único usuário em O(k² × n_avaliações_do_usuário) — muito mais barato do que retreinar tudo, pois mantém os vetores dos filmes fixos e só resolve o sistema linear para o usuário novo.

Limitação 3 — 18,10% de variância explicada

LIMITAÇÃO

50 componentes capturam apenas 18,10% da variância total da matriz centralizada. O restante (81,9%) não foi modelado.

O que significa cada % de variância Variância total da matriz R̃ ≈ soma de todos os autovalores de R̃ᵀR̃

λ₁ + λ₂ + ... + λ₁₂₃₁₅ = variância total
λ₁ + λ₂ + ... + λ₅₀ = 18.10% desse total

→ Os 50 componentes capturam os padrões de preferência mais compartilhados.
→ Os 12.265 componentes restantes capturam variações de nicho ou ruído individual.

Por que 18% pode ser suficiente

Com 99,74% de esparsidade, grande parte da variância é ruído de amostragem. Capturar mais variância pode significar memorizar padrões que não se generalizam.

Por que pode ser insuficiente

Preferências de nicho (filmes de arte obscuros, documentários específicos) ficam fora dos 50 componentes. Usuários com gostos incomuns são mal representados.

Extensão 4: testar k = 100, 200, 500 e plotar RMSE de validação × k. O ponto onde a curva "achata" é o k ótimo. Custo: a matriz de similaridade item-item cresce como O(k × n²), então k maior tem custo computacional significativo.

Limitação 4 — Precision@10 restrita ao teste

LIMITAÇÃO

Como explicado na Lição 6, os candidatos para avaliação são apenas filmes que o usuário avaliou no teste — não o catálogo inteiro de 12.315 filmes.

Por que isso infla a métrica Candidatos por usuário no teste: ~15–30 filmes
Candidatos no catálogo completo: 12.315 filmes

Com 15 candidatos e limiar 4.0: suponha 8 são relevantes (nota ≥ 4.0)
Precision@10 máxima possível: min(10, 8) / 10 = 0.80

Com 12.315 candidatos: os 10 melhores precisam competir com muito mais filmes irrelevantes.
Precision@10 real em produção seria muito menor que 0.57.
Extensão 3 — Leave-one-out: para cada usuário, remove uma avaliação do treino, treina o modelo, e verifica se o item removido aparece no top-k recomendado. Os candidatos são todos os 12.315 filmes do catálogo — métrica muito mais realista, mas computacionalmente cara (requer retreinar n vezes).

Extensão 1 — ALS vs. SVD: a diferença técnica central

EXTENSÃO

O SVD minimiza o erro sobre todas as entradas da matriz — incluindo os zeros ausentes, que são tratados como "nota zero". O ALS minimiza o erro apenas sobre as entradas observadas.

Função de perda do SVD

min Σtodos i,j (R̃[i,j] − uᵢᵀvⱼ)²

Inclui os ~9,57 bilhões de zeros ausentes. O modelo "aprende" que nota ausente = 0.

Função de perda do ALS

min Σ(i,j) observados (r[i,j] − uᵢᵀvⱼ)²

Ignora entradas ausentes. Zeros ausentes não contaminam o aprendizado.

Como o ALS resolve: alternando entre fixar U e fixar V 1. Inicializa V aleatoriamente
2. Fixa V → resolve sistema linear para cada linha de U:
uᵢ = (VᵀV + λI)⁻¹ Vᵀ rᵢ (só usa entradas observadas de i)
3. Fixa U → resolve sistema linear para cada coluna de V
4. Repete até convergir

λ é regularização (evita overfitting). A centralização não é necessária porque
o ALS não confunde zeros ausentes com notas zero.
