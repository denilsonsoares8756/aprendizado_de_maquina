Similaridade de Cosseno
entre Itens — Exemplo Numérico

Missão: Você vai apresentar o Slide 7 sobre Similaridade de Cosseno em ~1min 30s. Esta lição constrói a intuição numérica para você explicar o cálculo com confiança, mesmo sob perguntas.

O que é a fórmula

Após o SVD, cada filme i vira um vetor vi de 50 números (os chamados fatores latentes). A similaridade de cosseno entre dois filmes mede o ângulo entre esses vetores — quanto menor o ângulo, mais similares os filmes.

sim(i, j) = (vᵢ · vⱼ) / (‖vᵢ‖ · ‖vⱼ‖)

O resultado sempre cai no intervalo [−1, 1]. No nosso caso, como as notas foram centralizadas (desvios em relação à média do usuário), os vetores podem ter componentes negativas — mas na prática o score fica próximo de [0, 1] para filmes com alguma afinidade.

Exemplo numérico com vetores de 3 dimensões

No modelo real, cada vetor tem 50 dimensões. Aqui usamos 3 dimensões para que o cálculo caiba em papel. O processo é idêntico — só há mais termos.

Imagine que o SVD aprendeu três fatores latentes para representar cada filme:

Filme Fator 1
("drama autoral")		 Fator 2
("comédia")		 Fator 3
("ação")
A Fish Called Wanda 0.2 0.9 0.1
Monty Python e o Cálice Sagrado 0.1 0.8 0.2
Exterminador do Futuro 0.0 0.1 0.9
Os rótulos ("drama autoral", "comédia") são ilustrativos. O modelo não rotula os fatores — eles emergem automaticamente dos padrões de co-avaliação.

Passo 1 — Produto escalar (numerador)

Wanda · Monty Python (0.2 × 0.1) + (0.9 × 0.8) + (0.1 × 0.2)
= 0.02 + 0.72 + 0.02
= 0.76

Wanda · Exterminador (0.2 × 0.0) + (0.9 × 0.1) + (0.1 × 0.9)
= 0.00 + 0.09 + 0.09
= 0.18

Passo 2 — Norma de cada vetor (denominador)

A norma ‖v‖ é a raiz da soma dos quadrados das componentes:

‖Wanda‖ √(0.2² + 0.9² + 0.1²) = √(0.04 + 0.81 + 0.01) = √0.86 ≈ 0.927

‖Monty Python‖ √(0.1² + 0.8² + 0.2²) = √(0.01 + 0.64 + 0.04) = √0.69 ≈ 0.831

‖Exterminador‖ √(0.0² + 0.1² + 0.9²) = √(0.00 + 0.01 + 0.81) = √0.82 ≈ 0.906

Passo 3 — Similaridade final

sim(Wanda, Monty Python) 0.76 / (0.927 × 0.831) = 0.76 / 0.771 ≈ 0.986 ← muito similares ✓

sim(Wanda, Exterminador) 0.18 / (0.927 × 0.906) = 0.18 / 0.840 ≈ 0.214 ← pouco similares ✓

Wanda e Monty Python têm sim ≈ 0.99 — seus vetores apontam quase na mesma direção no espaço latente. O Exterminador fica longe: sim ≈ 0.21. Isso replica exatamente o resultado do slide (filmes Monty Python aparecem entre os mais próximos de Wanda).

Como isso vira uma recomendação

Suponha que o usuário avaliou dois filmes com essas notas:

Filme do históricoNota do usuário
A Fish Called Wanda5.0
Exterminador do Futuro2.0

Para cada candidato de recomendação, somamos os scores ponderados pela nota:

score(Monty Python) = sim(Wanda, Monty Python) × nota_Wanda + sim(Exterminador, Monty Python) × nota_Exterminador

Precisamos de sim(Exterminador, Monty Python):
(0.0×0.1 + 0.1×0.8 + 0.9×0.2) / (0.906 × 0.831) = (0 + 0.08 + 0.18) / 0.753 ≈ 0.345

score(Monty Python) = (0.986 × 5.0) + (0.345 × 2.0)
= 4.93 + 0.69 = 5.62

O score alto (5.62) indica que Monty Python deve aparecer no Top-10 deste usuário — puxado principalmente pela nota 5.0 em Wanda, que tem alta similaridade com ele.

Por que cosseno e não distância euclidiana?

A distância euclidiana é sensível à magnitude dos vetores. Filmes muito avaliados tendem a ter vetores de maior norma, o que os favoreceria artificialmente. O cosseno mede só o ângulo — normaliza pela norma — então um filme de nicho com poucas avaliações pode ser tão similar a outro quanto um blockbuster, se os padrões de co-avaliação forem parecidos.
