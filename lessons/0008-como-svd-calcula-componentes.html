Como o SVD Calcula
os Pesos dos Filmes

Foco: Na Lição 7 os pesos dos filmes (+0.58, −0.50...) foram dados prontos. Aqui você vai ver de onde eles vêm — o SVD os obtém calculando os autovetores da matriz de correlação entre filmes R̃ᵀR̃.

O exemplo mínimo: 3 usuários, 2 filmes

Para fazer o cálculo caber na mão, usamos apenas 2 filmes — Titanic e Gladiador — com 3 usuários já centralizados:

TitanicGladiador
Ana+1.0−1.0
Bruno−0.8+0.8
Carla+0.9−0.9

Ana e Carla sempre deram notas opostas para Titanic e Gladiador. Bruno também — só que invertido. O padrão é claro: quem gosta de um, não gosta do outro.

Passo 1 — Calcular R̃ᵀR̃: a matriz de correlação entre filmes

O SVD precisa encontrar uma direção no espaço dos filmes que explique o máximo da variação dos usuários. Para isso, calcula R̃ᵀR̃ — uma matriz filmes × filmes onde cada entrada mede o quanto dois filmes foram avaliados de forma parecida.

(R̃ᵀR̃)[i, j] = Σ_u r̃_ui × r̃_uj

Em português: multiplica as notas centralizadas de cada usuário para os dois filmes e soma.

(R̃ᵀR̃)[Titanic, Titanic] = soma dos quadrados da coluna Titanic Ana² + Bruno² + Carla²
= (+1.0)² + (−0.8)² + (+0.9)²
= 1.00 + 0.64 + 0.81 = 2.45

(R̃ᵀR̃)[Titanic, Gladiador] = produto entre as duas colunas Ana: (+1.0) × (−1.0) = −1.00
Bruno: (−0.8) × (+0.8) = −0.64
Carla: (+0.9) × (−0.9) = −0.81
Soma = −2.45

(R̃ᵀR̃)[Gladiador, Gladiador] = soma dos quadrados da coluna Gladiador (−1.0)² + (+0.8)² + (−0.9)² = 1.00 + 0.64 + 0.81 = 2.45

A matriz R̃ᵀR̃ completa:

TitanicGladiador
Titanic+2.45−2.45
Gladiador−2.45+2.45
O que essa matriz diz: a diagonal (+2.45) mostra que cada filme tem variação própria. A entrada cruzada (−2.45) é fortemente negativa — Titanic e Gladiador são avaliados em direções opostas por todos os usuários.

Passo 2 — Encontrar o autovetor de R̃ᵀR̃

O autovetor (eigenvector) associado ao maior autovalor de R̃ᵀR̃ é o Componente 0. Para uma matriz 2×2 simétrica da forma [[a, b], [b, a]], os autovetores são sempre [+1/√2, +1/√2] e [+1/√2, −1/√2].

Verificando o autovetor v = [+1/√2, −1/√2] ≈ [+0.707, −0.707] R̃ᵀR̃ × v = ?

Linha Titanic: (+2.45 × +0.707) + (−2.45 × −0.707) = 1.732 + 1.732 = +3.464
Linha Gladiador: (−2.45 × +0.707) + (+2.45 × −0.707) = −1.732 − 1.732 = −3.464

Resultado: [+3.464, −3.464] = 4.90 × [+0.707, −0.707] ✓

→ O vetor [+0.707, −0.707] é de fato um autovetor com autovalor λ = 4.90.
Este autovetor É o Componente 0:
Titanic: +0.707 ← peso positivo (lado "drama")
Gladiador: −0.707 ← peso negativo (lado "ação")

O SVD não "adivinhou" esses pesos — eles foram derivados matematicamente da correlação entre as colunas da matriz.

O autovalor λ = 4.90 é a variância explicada

O autovalor indica o quanto de variação da matriz esse componente captura. A variância total da matriz é a soma de todos os autovalores. Nesse caso com 2 filmes há 2 autovalores: λ₁ = 4.90 e λ₂ = 0.

Variância explicada pelo Componente 0 λ₁ / (λ₁ + λ₂) = 4.90 / (4.90 + 0) = 100%

Faz sentido: com apenas 2 filmes perfeitamente opostos, 1 componente explica tudo. No modelo real com 12.315 filmes, 50 componentes explicam 18.10% — o restante é ruído.

Por que o modelo real não faz isso na mão

No modelo real, R̃ᵀR̃ tem 12.315 × 12.315 = 151,7 milhões de entradas. Calcular autovetores de uma matriz tão grande por álgebra direta é impraticável. O TruncatedSVD do sklearn usa um algoritmo iterativo (ARPACK) que encontra apenas os k maiores autovalores sem montar a matriz inteira.

O que o código faz sob o capô:
svd.fit_transform(train_matrix_centered)

1. Itera multiplicando vetores pela matriz R̃ (e R̃ᵀ) repetidamente
2. Após cada iteração, o vetor converge para a direção do maior autovalor
3. Subtrai esse componente e repete para o próximo
4. Para após encontrar os 50 maiores — os restantes 12.265 são ignorados

Resumo: de onde vêm os pesos dos filmes

EtapaO que acontece
1. R̃ᵀR̃Calcula correlação entre cada par de filmes
2. AutovetorEncontra a direção que maximiza a variância dos usuários
3. item_factors[:, k]São as componentes desse autovetor — um peso por filme
4. Repete k vezesCada componente captura o próximo padrão residual
